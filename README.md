# Eteocypriot research corpus

Building an attributed, reproducible corpus and offline research toolkit from licensed source evidence. Eteocypriot language interpretations remain unresolved; known syllabic sign values do not establish translations. Initial source scope: 26 candidates from BBAW / TELOTA IG XV 1, preserved via the Cypriot syllabic Greek 1.0 snapshot. Candidate counts are not independent inscription counts. Source uncertainty, bilingual components and malformed XML are tracked explicitly.

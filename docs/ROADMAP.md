# Roadmap

0.1: admit 26 licensed candidate source responses with immutable provenance.
0.5: component-level language assertions, offline tools and conservative exports.
0.9: adversarial tests, export/source replay and family identity reconciliation.
1.0: stable source-attributed component snapshot and research toolkit, with one
explicit source quarantine. This milestone does not establish exhaustive coverage,
independent epigraphic review or a decipherment.

After 1.0: broaden source acquisition beyond this fascicle; add attributed
concordances, object identity and alternative-edition apparatus; obtain expert
review for selected readings. Cross-project adapters must preserve source lineage,
rights, native units and uncertainty. Linguistic relationship claims require their
own evidence and known-answer controls.

The user-provided expansion queue is Eteocretan (priority 3) and Lycian/Carian
(priority 4), in their dedicated repositories. The Arkalochori bronze axe belongs
in a separate disputed-Cretan object register, linked to the Cretan Hieroglyphic,
Linear A and Phaistos Disc projects. It is not an Eteocypriot or Eteocretan text.
